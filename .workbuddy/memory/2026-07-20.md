## 第十一轮紧急修复(用户反馈"发生了什么"——td 标签被破坏)

- **【严重 bug】** 上一轮 Python 脚本 `unify_td_height.py` 的 regex `<td width="50%"[^>]*style="([^"]+)"` 配合 add_min_height 函数只返回 `style="..."`,导致 regex 匹配的 `<td width="50%" align="center" valign="middle"` 部分被删除,10 个 td 标签全部变成残缺的 `style="..."` 开头,HTML 结构彻底破坏,GitHub 渲染时表格布局崩溃。
- **修复方案**: 写 `fix_td_tags.py` 脚本,用 regex `^    style="(background-color:#f7f1e3;[^"]+)"` 匹配残缺行,根据内容判断 td 类型(padding:10px 是图片 td,加 align="center";padding:18px 22px 是文字 td,不加 align),在前面恢复 `<td width="50%" valign="middle"` 或 `<td width="50%" align="center" valign="middle"`。
- **验证**: 10 个 td 全部修复,每个都有完整标签结构 + min-height:280px。文字 td 5 个(无 align),图片 td 5 个(有 align="center")。
- **教训**: Python regex 替换时,re.sub 的 repl 如果只返回部分内容,会删除匹配中的其他部分。应该返回完整的匹配内容(包括 `<td width="50%"...` 前缀),而不是只返回 `style="..."`。正确做法:用捕获组保留前缀,repl 中用 `\1` 引用。

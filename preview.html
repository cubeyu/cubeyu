◈ 关于本预览与 GitHub 实际渲染的差异

本预览页加载了 Google Fonts 古风字体（志莽行 / 马善政 / 龙藏 / 刘建毛草 / 站酷小薇），呈现"理想效果"。

README.md 用于 GitHub 个人主页，因 GitHub HTML 过滤器会移除 style / class / <style> / <link>，故改用 SVG 内嵌 font-family + 系统古风字体兜底链。

在 GitHub 上查看 README.md 时：

  • Windows 用户可见 楷体（KaiTi） / 仿宋（FangSong）
  • macOS 用户可见 华文楷体（STKaiti） / 华文仿宋（STFangsong）
  • Linux 用户若未装中文字体，会回退到默认 serif

水墨元素（远山、墨竹、印章、分割线）均为内联 SVG，GitHub 完整渲染，与本预览一致。

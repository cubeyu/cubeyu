# 项目改动描述

## GitHub 个人主页美化项目 - 古风水墨画风格

### 创建时间
2026-07-19

### 版本记录

#### v2.0 - 古风水墨画风格（当前版本）
- **改动时间**: 2026-07-19
- **风格定位**: 中国传统水墨画风格，融入山水、印章、宣纸等文化元素
- **配色方案**:
  - 墨色 `#2C2C2C` - 主背景色
  - 宣纸色 `#F5F0E8` - 文字主色
  - 朱砂红 `#C9372C` - 强调色、印章色
  - 竹青色 `#7CB9A8` - 辅助色
- **设计特色**:
  - 顶部「墨韵代码」书法标题横幅
  - 个人印章效果徽章
  - 「行到水穷处，坐看云起时」竖排座右铭
  - 卷轴风格的「关于我」信息卡
  - 分类命名的技术栈：笔墨（语言）、丹青（前端）、机关（后端）、器物（工具）
  - 底部「山水有相逢」波浪页脚
  - 贡献蛇图更名为「墨龙」

#### v1.0 - 卡片式科技风格
- **改动时间**: 2026-07-19
- **风格定位**: 现代卡片式设计，Tokyo Night 深色主题
- **配色方案**:
  - 主色调 `#00D9FF`（青色）
  - 背景色 `#0D1117`
  - 强调色 `#FF6B6B`
- **状态**: 已重构为 v2.0

### 使用的第三方服务
- `readme-typing-svg.demolab.com` - 书法打字机效果
- `github-readme-stats.vercel.app` - 修行统计卡片
- `github-readme-streak-stats.herokuapp.com` - 连续修行统计
- `github-profile-trophy.vercel.app` - 修行成就奖杯
- `github-readme-activity-graph.vercel.app` - 修行轨迹图表
- `Platane/snk` - 墨龙图生成
- `shields.io` - 技术栈徽章（古风配色）
- `komarev.com/ghpvc` - 访客计数
- `capsule-render.vercel.app` - 水墨横幅（马善政书法字体）
